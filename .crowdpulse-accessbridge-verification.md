# CrowdPulse and AccessBridge verification

CrowdPulse was verified in the managed browser with six sample reports and three incident clusters. The Perambur road-flooding cluster shows three related reports, a 0.47 km geographic spread, 12% semantic similarity, the latest report time, and a CONFLICTING status. The page visibly distinguishes community intelligence from the official warning feed and repeats that clusters never become official warnings automatically. The report ledger retains report text, location, category, source, timestamp, and verification status.

AccessBridge was verified with the visible Emergency access switch in the global workspace header and a dedicated AccessBridge route. The browser interaction switched the same four ActionForge actions to Tamil, enabled large-text mode, and enabled browser-native voice playback. The UI preserves priorities, source, confidence, evidence category, and the same-safety-meaning notice. The implementation uses SpeechSynthesis with no paid voice provider.

Validation completed with 18 passing Vitest tests, a clean TypeScript check, and a successful production build.
