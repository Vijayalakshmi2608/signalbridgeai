# Official source verification

The live-source integration research used these official sources:

- India Meteorological Department API information: https://mausam.imd.gov.in/responsive/apis.php
  The page confirms IMD provides official warning services and links to API documentation and the IMD API portal; technical access may require endpoint/station details and IP whitelisting.

- IMD API Management Platform: https://api.imd.gov.in/
  The portal describes a unified gateway for real-time observations, forecasts, warnings, and specialized bulletins.

- NDMA SACHET National Disaster Alert Portal: https://sachet.ndma.gov.in/
  The portal publishes authorized government disaster warnings and describes a CAP-integrated system with geo-targeted alerts and an India CAP RSS feed.

- NDMA SACHET RSS subscription page: https://sachet.ndma.gov.in/CapFeed
  The official page provides RSS subscription and a user guide; the actual feed URL is not exposed in the extracted page, so the adapter must remain configurable rather than inventing an endpoint.

- Greater Chennai Corporation Storm Water Department: https://chennaicorporation.gov.in/gcc/department/storm-water/
  The official page documents Chennai's flood/stormwater context and city drainage responsibilities. It is used for provenance context only, not as a fabricated live-alert endpoint.

Implementation decision: expose configurable LIVE_WARNING_FEED_URL / LIVE_WARNING_FEED_NAME / LIVE_WARNING_FEED_TYPE server variables. If no feed URL is configured, the app reports official feeds as unconfigured and safely serves the clearly labeled demo dataset. Do not claim live official connectivity until a verified feed is configured.
